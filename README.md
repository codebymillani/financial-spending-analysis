# Olist E-Commerce Customer Analysis

## Overview
This project looks at customer purchase data from the Olist Brazilian E-Commerce dataset. The goal was to clean and analyze the data, identify customer spending patterns, and visualize trends using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
- Olist Brazilian E-Commerce Public Dataset (Kaggle)

## What I Did
- Cleaned and prepared the data by handling missing values and formatting dates.
- Combined multiple datasets using Pandas.
- Created new features like purchase month and delivery time.
- Used RFM analysis to group customers based on their purchasing behavior.
- Built visualizations to explore revenue, customer segments, and sales trends.

## Key Takeaways
- A small group of customers accounted for a large portion of total revenue.
- Order activity changed over time, showing clear monthly trends.
- Some states generated much higher sales than others.
